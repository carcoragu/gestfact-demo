Flujo de activación
1. El cliente confirma el pago → vos lo cobrás
2. Completás este formulario y tocás "Activar plan"
3. El plan se guarda en el servidor del cliente de inmediato
4. La próxima vez que el cliente abra AnotDigi, ya tiene el plan activo
5. El link de backup sirve si el cliente abre AnotDigi offline
